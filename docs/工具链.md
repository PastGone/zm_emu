一、构建编译工具：XMake
项目编译构建选用 XMake，放弃传统 Makefile、CMake，核心理由：
语法友好：基于 Lua 语言形态，相比 Makefile/CMake 更容易理解、编写；
适配项目远期规划：项目成熟后可借助配套能力将整体代码编译为 WASM，适配网页外部平台。
二、图形画面渲染库：SDL
画面层底层依赖 SDL（游戏开发多媒体库），选型依据：
成熟稳定、经过大量工程验证，大量模拟器项目均采用 SDL 开发；
支持编译输出 WASM，是项目后续网页端部署的基础支撑。
三、核心指令模拟库：unicorn
为本项目工具链最核心组件，定位是 Qemu 的精简版本，核心作用是完成指令模拟与执行，承担项目底层仿真能力。
四、辅助工具开发语言：Golang
用途：编写项目配套各类工具脚本、工具程序；
技术迁移：工具代码原本使用 Python 开发，现已迁移至 Golang；
选用 Golang 的优势：跨平台能力更强，可直接打包生成轻量化独立可执行文件；
当前现状：项目内基于 Go 开发的工具代码较少，主要是因为我比较懒。
五、整体工具链总览与结尾
整套工具链由 XMake（构建）+ SDL（图形）+ unicorn（核心指令模拟）+ Golang（辅助工具） 组成，介绍完四类组件后无其他配套技术，讲解结束。
